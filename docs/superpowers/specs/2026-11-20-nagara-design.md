# nagara（仮）設計

作成日: 2026-11-20

## 目的
作業中にブラウザの全画面タブで横に流しておく、眺めるためのビジュアル。主張しすぎず、見るたびに少し違っているものにする。
雰囲気は「アクアリウム」。ただし生き物（魚）は登場させず、水草・泡・光・水そのものを主役にした水草水槽を横から眺める画にする。
- 音が鳴っていれば、その音に反応して水槽の中が動く
- 音がなくても、時間帯に合わせて水槽の照明がゆっくり変わる

## 目標
- 開いて放っておけば、ずっときれいに動き続ける
- 音楽を流すと、リズムや音量に合わせて反応しているのが分かる
- 朝・昼・夕・夜で照明が変わり、その間も途切れずに移り変わる

## やらないこと（今回は）
- 魚などの生き物（ユーザーの指定。海月だけは入れてよい）
- 曲名の識別、録音や保存
- 作り込んだ設定画面
- スマホ向けの最適化（動けばよい程度）
- Electron 版（後から包めるように作っておく）

## 失敗とみなすこと（動いていてもダメなもの）
- 目に痛い点滅や激しいフラッシュ。作業の邪魔になる
- 重くてファンが回る、他の作業が遅くなる
- マイクを拒否すると何も表示されない

## 制約
- ブラウザだけで動くこと（サーバーなし）
- マイク入力はブラウザの許可が必要。初回にユーザー操作（クリック）が要る

## 検討した作り方
| 案 | 長所 | 短所 |
|---|---|---|
| **ブラウザ版（TypeScript + Canvas + Web Audio API）** ← 採用 | 軽い。URL だけで開ける。ポートフォリオに載せやすい | 壁紙のような使い方はできない |
| デスクトップ版（Electron） | 最前面表示や半透明表示ができる。耳帖と同じ技術 | 作る量も配布の手間も倍 |
| Processing / p5.js スケッチ | 一番早く動く | 後から機能を足して育てにくい |

目的（ながら用途、音と時間帯の両方に反応、アクアリウム風、魚なし）はユーザーが決めた。作り方は Claude が提案し、了承を得た。

### 水槽の要素
- 背景：奥ほど暗くなる水のグラデーション
- 光の筋：水面から差し込む光の帯。ゆっくり揺れる
- 水草：下から伸びる数十本の草。根元は固定し、先端ほど大きく揺れる
- 泡：底のあちこちから昇り、水面で消える
- 浮遊物：小さな光の粒がゆっくり漂う
- 石・流木：底のシルエット（動かない）。起動ごとに配置を少し変える
- 海月：2〜3匹。半透明の傘と細い触手で、ふわふわ漂う（ユーザーの指定で、生き物はこれだけ）。傘を開閉しながらゆっくり上下し、画面の端に来たら向きを変える。夜は自分でほのかに光る

### 時間帯の照明（端末の時刻を使う）
- 朝 5–10時：ライトが少しずつ点き、淡い緑と水色になる
- 昼 10–16時：明るく澄んだ青緑。光の筋が一番はっきり見える
- 夕 16–19時：暖色の照明。橙がかった水
- 夜 19–5時：青い月光ライト。全体が暗くなり、動きもゆっくりになる
- 境目は約1時間かけて補間し、切り替わりが目に見えないようにする

### 音への反応（Web Audio の AnalyserNode）
- 全体の音量：光の筋の明るさと浮遊物の輝き
- 低音：水草全体が水流に押されたように大きくそよぐ
- 高音：泡が多めに湧き上がる
- 拍（低音が急に強くなった瞬間）：底から泡がまとまってぽこっと昇り、光の筋が一瞬ゆらぐ。海月が傘をきゅっと閉じて、少し上に進む
- 音量：海月の傘のほのかな光
- 変化には必ずなめらかさ（減衰）をかけ、急な明滅を出さない

### 無音のとき・マイク拒否のとき
- 時間帯の照明の中で、水草がゆるく揺れ、泡がときどき昇るだけになる

## 技術（Claude の判断）
- Vite + TypeScript、描画は Canvas 2D。外部ライブラリなし
- ファイル分け：`palette.ts`（時間帯の照明）、`audio.ts`（マイクと周波数分析）、`scene/`（光・水草・泡・浮遊物・底）、`main.ts`（ループ）
- 確認用に URL パラメータ `?hour=20` で時刻を上書きできる
- GitHub リポジトリ `0kimuchi0/nagara`、GitHub Pages で公開
- 60fps を目標にし、泡や浮遊物の数には上限を設ける

## 作る人に任せること
- 具体的な色コード、水草の本数、減衰の強さなどの調整値
- 拍の検出の細かい閾値
